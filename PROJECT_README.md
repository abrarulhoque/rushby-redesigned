# Rushby Industries - Homepage Redesign

A modern, professional homepage redesign for Rushby Industries built with Next.js, Tailwind CSS, Shadcn UI, and Framer Motion.

## 🚀 Quick Start

```bash
cd rushby-redesign
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
